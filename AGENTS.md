# Manutenção do site Schiecchi

Este repositório publica https://schiecchi.com.br/ pelo GitHub Pages a partir da branch `main` e da raiz do repositório.

Antes de qualquer alteração no site:

1. Verifique se há alterações locais não registradas. Preserve-as e não as sobrescreva.
2. Rode `git fetch origin` e confira se a branch local está atrás de `origin/main`.
3. Se estiver trabalhando na branch `main` e a árvore estiver limpa, rode `git pull --ff-only origin main`. Se houver alterações locais ou divergência, integre-as com cuidado antes de editar. Em uma worktree em outra branch, atualize a base com `origin/main` antes de alterar o site.
4. Só então edite, confira o resultado, crie um commit e envie ao GitHub conforme o pedido do usuário. Mudanças em `main` publicam automaticamente pelo GitHub Pages.

O site atual é uma página provisória com o logotipo Schiecchi Mecatrônica e o texto "Em breve". O pai do proprietário pode pedir mudanças nesta tarefa do Codex. Use as informações que ele fornecer; não invente dados comerciais, contatos ou serviços.
